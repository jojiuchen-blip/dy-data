# dy-data Web

React 19 + TypeScript + Vite 前端，承载需要登录的经营看板、结算复核、订单明细、线索运营和后台管理。

## 数据与认证

- 真实 `/api/v1` 是默认数据源，请求通过共享 client 发送并携带会话凭据。
- `AuthGate` 负责登录态页面体验；角色和门店数据权限仍由 FastAPI 后端执行。
- `VITE_USE_MOCKS=true` 只用于显式受控开发，不得静默掩盖真实 API 错误。

## 当前路由范围

- 登录、销售、门店排名、月度结算和订单明细。
- 线索总览、线索详情与跟进。
- 账号、SKU、非佣金归属账号、商品类型可见性、反馈和同步管理。
- 线索分配规则、试运行、记录、总部池和门店评分等管理页面。

准确路由以 `src/App.tsx` 为准，接口以 `src/api/` 和后端 schema 为准。

### 线索分配演示模式

```powershell
npm run dev:demo
```

演示模式仅在 Vite 开发环境生效，自动使用“演示最高管理员”和合成线索数据，不连接真实业务 API。跟进、试运行、重建和规则操作只修改当前浏览器会话内存，刷新页面后恢复初始数据。

### 线索中心新手引导

拥有“线索明细”权限的账号，在 `/clues` 或 `/clues/details` 首次进入时可接受引导邀请，也可选择“稍后再看”。页面上的“新手引导”入口始终可重播；关闭偏好按账号和浏览器保存，存储不可用时在当前会话内生效。

引导依次介绍线索明细、状态筛选、查看详情、联系方式、跟进结果与备注、保存、跟进历史。它保留当前筛选，只从当前列表选择线索，优先介绍待跟进且可操作的轮次。没有结果时在列表结束；只读轮次跳过填写与保存说明；加载失败或目标缺失时可以退出。

“下一步”只切换介绍位置、滚动或打开详情，不查看/复制完整手机号、不导出、不填写或保存跟进。已有详情打开时不能启动引导，避免影响正在填写的内容。支持上一步、跳过、Escape、键盘焦点恢复及减少动态效果。

专项验证从仓库根目录运行 `python -m pytest tests/test_visual_clue_onboarding.py -q`。测试使用本地 FastAPI 实路由与合成数据，截图写入 `DYDATA_TOUR_ARTIFACT_DIR` 指定的仓库外目录，未指定时使用 pytest 临时目录。

## 实现约束

- 视觉与组件规范读取 `../../docs/design-system/README.md` 和 `../../docs/design-system/tokens.json`。
- 页面不复制结算、线索分配或权限业务规则；后端输出业务结果，前端负责状态与交互呈现。
- 接口型页面至少处理加载、空数据、错误、无权限和正常状态。
- 可保存功能必须用真实 API 验证提交后重新加载的回显一致性。
- 不提交 API 密钥、Cookie、生产 URL、真实个人数据或本地路径。
