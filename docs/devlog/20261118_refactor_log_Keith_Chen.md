# 2026-11-18 开发日志

## DYDATA-115 商品流转与门店跟进

商品的规则版本在首次入库时固定，适用门店名单在实际选店时读取。本品缺名单时按原门店直派。已启用的商品按销售店、同城 10 公里、同城兜底执行，系统保留每次真实接收的独立任务和跨轮历史。商品开启时校验负责人预览的名单版本，可逐商品重试。

门店可提交预约及改约。到期消费者、跟进提交和订单终态复核在同一线索上串行。两张看板和分配评分使用共同的任务级事实，自店量另外按门店、订单及首次有效核销日核算。

联调中修复了三处跨模块问题。总部确认能立即使用新补齐的原门店映射。数据库时间在预约回读时携带时区。旧应用在新版看板预热后仍能按原列读取冻结数据。

工程测试、两看板的样本计数和生产启用条件见[研发验收记录](../verification/dydata-115-verification.md)。上游历史口径的六项回捞请求已登记，等待文档负责人评审。见 [Foundation 变更请求](../plans/foundation-plans/foundation-change-requests-dydata-115.md)。
