# 线索核销事实展示与延迟回填

## 行为变化

线索详情移除重复的“核销状态”。保留核销门店名称（缺名称时显示已有门店 ID）；已核销但门店事实缺失时显示“核销门店暂缺”，不再将缺失误报为未核销，也不承诺正在同步。

“仅看自店核销”筛选及导出按本轮分配门店与实际核销门店相同判断，不要求已经预约或跟进成功。原有 `is_self_store_verified` 考核条件保持不变；未知门店不归入异店。

上述事实筛选仅用于线索明细及导出；线索看板和静态统计发布继续使用原有考核筛选契约，避免改变既有统计口径。

## 数据处理

订单状态与核销明细是独立事实。过去关闭线索后投影可能不再更新历史轮次，出现已核销但轮次核销门店缺失。现在沿用已有 `settlement_order_details`，在投影任务补齐最新正式关闭轮次。

全量每次最多选取 200 个可修复轮次，增量限定输入订单；保留 master → round → center 锁顺序。候选保留 master 和轮次身份，不会因同订单多来源而漏补。多券优先匹配本轮门店，无匹配时优先有门店 ID 的事实，同门店可补名称。回填不清空已有非空字段，不重新激活线索，不改变分配和跟进历史。

终态回填不触发手机号解密，不新增抖音接口采集、数据库迁移或全库重算。库内无核销明细时仍保持未知；代码合并不等同于线上历史数据已经修复。
