## 迁移与运行边界

追加 `20260907_0051`，只为 `clue_center_orders` 添加 nullable `phone_source_fingerprint`。旧电话字段不被伪造来源证明；当前 API 从原始源重验，Worker 在投影刷新时写入新指纹。来源不可验证的完整电话暂不可用，不能以旧缓存补齐。

回滚该迁移只删除新列，必须与应用版本配套。旧应用没有来源验证能力，因此数据库可回滚不代表恢复旧版本后仍具备本轮电话保护。没有执行生产迁移或数据回填。

本次 PostgreSQL 验证使用本任务独立本机容器、随机测试 schema，不连接真实数据库。自动正式分配与再分配保持关闭；没有部署、推送或更改其他 issue 状态。
