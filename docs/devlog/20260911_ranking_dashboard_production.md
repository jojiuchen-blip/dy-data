# 抖音打榜看板生产接入核验

## 已确认口径

- 独立入口 `/metrics/douyin-ranking`，预留后续星评看板；集团、服务中心、大区、区域、门店五个层级。
- 数据下限北京时间2026-09-01；默认2026-09-07至当天，可选择日期。
- 订单量读取已有精诚养车 SKU 白名单，门店及明确绑定职人的全渠道订单按订单ID去重，不沿用结算渠道过滤。
- 店均分母采用**统计开始日**有效的精诚养车适用门店名单，含零销量门店。用户于本轮明确确认，期中名单更新不改变同一开始日的分母版本。
- 正式分配轮次立即计入24小时跟进率分母，包括未满24小时的轮次；同店未删除有效跟进且发生于分配后24小时内计分子。辅助“跟进率”无24小时时限。
- 自店核销率按 `(订单ID, 正式分配门店)` 责任样本计分母；关联券在分配之后成功、未撤销且于本店核销才计分子。异店核销不计，不修改结算中心。
- 组织版本按线索首次正式分配时刻固定；历史版本、线索组织pin、已发布快照均保留。

## 实现与审查

- 正式查询只接受 `business` 快照，预览只读 `synthetic`；不再回退旧结算聚合。
- 快照缓存5分钟，页面可手动刷新并在可见状态每5分钟重读；修复后的源数据会进入后续计算。
- 账号与绑定一次预处理，识别抖音状态2/105、UID及精确名称；1待确认不视为成功。保留绑定时间缺失标志，冲突不猜归属。可选ID补齐不会使旧昵称/失效关系复活。
- PostgreSQL事务锁串行化名单和快照发布；SQL语句20秒上限、期间事实每查询5万行，维度5万行、组织历史及汇总读取25万行上限，超量拒绝而非输出部分排名。

- CSV/XLSX/XLSM文件各10MiB、XLSX解压100MiB、最多2万门店；表头按业务字段解析，允许乱序和额外无关列。腾讯代理现有64MiB足够；Web镜像为该入口单独允许21MiB请求体。
