## 二、操作详情

### 任务 1：DYDATA-121 全量商品适用门店每日同步
- **目标**：把抖音已授权账号下的精诚养车和比亚迪本品适用门店全部纳入日同步，支持由 API 名单切回手动维护。
- **操作**：拉取各商品状态的完整目录，按商品保留最近一次核验成功的名单，商品管理页展示校验结果并支持预览采用。名单首次采用和流转开关分别授权。无历史手动版时，切回后保留当前有效名单，直到管理员上传并发布新名单。
- **结果**：专项后端与迁移 153 项通过，3 项按环境跳过；真实 PostgreSQL 12 项通过；浏览器专项 3 项通过。生产目录总量和首轮日同步状态待发布后核对。
- **涉及文件**：apps/worker/clue_routing_store_sync.py、apps/api/dy_api/clue_product_routing.py、apps/web/src/pages/AdminClueRoutingProductsPage.tsx、alembic/versions/20261125_0075_clue_product_douyin_store_scopes.py
