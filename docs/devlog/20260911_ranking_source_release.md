## 接口契约

`GET /api/v1/admin/ranking-source-evidence` 仅限最高管理员。

- 必填：`dataset`、`periodStart`、`periodEnd`、带时区的 `observedThrough`。
- 日期按北京时间解释，起止日均包含，最多 7 天；内部转为 UTC，结束边界不包含。
- `pageSize` 为 1–500，默认 500；`cursor` 是上一页返回的 `next_cursor`，翻页时保留原查询条件。
- 返回 `data.rows`、`data.has_more`、`data.next_cursor` 及范围、版本、限制等 `meta`。
- 订单集合为本期已知精诚养车成交订单与本期正式分配的已知精诚养车订单之并集。订单日期优先使用 `sale_time`，为空时使用 `pay_time`，不限制成交渠道或带货角色。

| dataset | 输出范围 |
|---|---|
| cohort | 上述订单 ID 并集 |
| orders | 集合内原始订单及带货账号、渠道 |
| assignment_rounds | 集合内截至观察时间的正式分配历史 |
| follow_records | 对应正式轮次的跟进记录及删除时间，不含备注与操作人 |
| coupons | 集合内订单与券的关联及状态 |
| verifications | 关联券的核销及撤销字段，保留实际 POI，不采用结算成功兜底 |
| bindings | 当前职人绑定，区分职人 UID 和结算账号 ID |
| accounts | 当前账号与门店归属 |
| poi_mappings | 当前 POI 与门店映射 |
| sku_rules | 当前精诚养车商品白名单 |

不输出完整原始 payload、手机号、昵称或跟进备注。不新增数据表和迁移，不改变结算、线索统计口径。主分支没有服务店编码字段时返回 null，并通过 `service_store_code_available=false` 明确能力，避免依赖本地看板迁移。

## 限制与保护

使用主键游标分页，每页最多取 501 行，不计算全表总数。PostgreSQL 设置当前事务查询超时 8 秒、锁等待 1 秒。错误返回不包含 SQL 或连接信息。证据读取器禁用 autoflush，仅查询；复用的既有认证依赖可能初始化权限配置，不能将全站认证描述为无任何写入。

`consistent_snapshot=false`：观察截止限制事件时间，不能冻结当前绑定、删除、撤销及白名单的历史版本。无法归类商品的正式分配、未关联券的核销需要另行核验。因此接口上线不等于已经完成真实数据覆盖验收，也不等于正式排名已可发布。
