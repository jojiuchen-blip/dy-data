## 实现事实

- 统一发布生命周期、五模块窄投影、来源计数、独立 worker、固定版本 HTTP 读取和导出。
- 核销券、打榜订单/责任轮次、线索概览、月结/财务分析分别冻结；原始响应和手机号不复制到新投影。
- 经营分析读取不执行重算；当前门店权限和总部池撤权立即生效。跟进、账单确认及发票工作流仍读取实时业务状态。
- 0063 显式冻结迁移 DDL 与来源跟踪，不依赖可变运行时列表；部署先预热后切 API，失败保留旧服务。
- 客户端统一版本、时间和错误状态，区分所选年度与全部历史；来源完整截止时间未知时不伪造。
