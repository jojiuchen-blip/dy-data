# 核销同步前人工跟进补计

需求见 [DYDATA-122](https://linear.app/keith-lim/issue/DYDATA-122)。开始时间为北京时间 2026-11-01 00:00，按正式下发时间判定。

实际核销时间仍用于核销归属和任务结束。指标额外核对同订单、同门店和同轮次的未删除人工跟进。提交发生在实际核销后、引擎首次记录到核销状态前，且未超过正式下发后 24 小时，可计入两项跟进指标。独立关单及改派继续截断本轮。核销前跟进证据保留实际时序。缺少观察证据的候选保留原统计。

状态事件表纳入两处看板源跟踪。复用现有发布进程和原有取数接口，源变更后发布修正后的完整快照。旧发布的读取协议兼容，已有任务、跟进、核销记录无需重写。
