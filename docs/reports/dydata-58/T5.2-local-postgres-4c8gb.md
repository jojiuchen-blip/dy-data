# DYDATA-58 本地 PostgreSQL 与 4C/8GB 验收报告

日期：2026-08-31

结论：**LOCAL POSTGRESQL + 4C/8GB RESOURCE GREEN / SERVICE-PROBE RELEASE BLOCKED**。

## 1. 验收环境

- Docker Desktop Linux 后端，WSL2 临时限制为 4 CPU、8 GB 内存、2 GB swap。
- 可丢弃 PostgreSQL 18 Alpine，仅绑定 `127.0.0.1:55432`，独立测试角色和数据库。
- 资源 fixture 为 155,000 行、1,550 个分区，约为当前 72,910 条线索量的 2.1 倍。
- 未连接、写入或重启腾讯云生产环境。
