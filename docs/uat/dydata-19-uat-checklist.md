# DYDATA-19 用户验收清单

## 验收边界

- 开票在系统外完成；系统不创建开票申请单、不执行开票，只登记信息、回传状态、查询、导出和保留审计。
- 门店账号提交推广服务费发票信息和账单异议。
- 财务人员在系统内使用管理员角色，导入外部已完成的推广费结果及管理服务费发票明细；系统内不再增加审核任务。
- 最高管理员与管理员业务权限一致，不设置按门店或区域的数据授权范围。
- Issue Owner 已授权：T5.7 全部硬门禁通过后无需二次确认，直接执行生产迁移与部署。测试、安全、迁移、CI、部署前备份或 smoke 任一失败时必须停止发布并记录结果。
