# DYDATA-104 月结与财务验收

## 销售归属和月结

十月起，订单原始销售抖音号名称与当月冻结名单精确匹配。必须对应一个实际账号、一家门店。资格取自同一条商家绑定记录的账号类型和认证状态。个人号曾经解绑时，仍可保留同一账号、同一门店有效的商家关系。

每笔新费用保存名称来源、冻结版本及摘要、账号、POI 和门店。重复计算应得到相同结果。明确不分佣的销售账号可提前排除。资格存疑或缺少相关商品、费率、实收、退款证据时，月结应区别能够确定的门店影响与未知影响。正式发布前核验底层费用证明、月结版本与权限。

共享的原始日采集、线索及核销表现继续运行。月末工作簿单独冻结。月结计算和逐店正式发布分别验收。

## 财务操作

| 入口 | 验收方法 |
| --- | --- |
| 推广及管理服务费下载 | 浏览器选择同一账期后下载 CSV。检查实际文件名、中文表头、办理状态、开票状态、费用总额、确认及发票金额。待生成账单的行可以展示费用。 |
| 其他分佣及财务下载 | 在同一发布版本核对筛选、所有命中行、受限门店、金额单位、日期和长编号文本。旧机读格式继续通过原有合同测试。 |
| 正式导入 | 在隔离 PostgreSQL 上传、预览并提交四类文件，再读数据库、页面、汇总、筛选和下载。按各自业务合同验证更正、撤销、重复与拒绝。 |
| 门店与 SAP | 普通门店资料保留 SAP 编码。独立 SAP 确认入口保留其原始记录和处理能力。 |
| 发票及厂家结果 | 固定已发布的账单范围和费用，实时读取合法的确认与单据状态。单据的新版本、撤销、历史筛选和分页均需核对。 |
