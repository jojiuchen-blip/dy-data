## 费用与查询

- 从十月起，月结核对订单原始销售名称和月末冻结账号。原名可凭同一账号和抖音号的历史记录关联到月底身份。归属优先采用当期有来源的账号到系统门店关系，其次核对唯一有效的原始 POI 映射。两种证据冲突时保留影响门店。
- 月结保存账期关系、原始字段、来源摘要和有效期。采集保留名称的字面内容，核对原始关联 POI 与存值，按已核实的字段语义处理 `scene_id`。任务重试读取已冻结的资格和门店证据版本。
- 总部及财务按现有费用方向和门店权限查看内部试算。全国榜单和财务页均提供门店汇总、逐券明细及各自的中文 CSV，各视图、筛选与下载锁定同一份试算。等待补证的金额留空，正式账单状态单独显示。[接口与筛选](../api/monthly-fee-trial.md)
- 页面默认上海上一自然月，支持手动切月、明确账期链接、确认后账单回查。已开票账单继续保留应计金额和原始明细。红冲或作废后手动重新加载释放账期时，先取得实际账期元数据，再校验原账单完整组。
