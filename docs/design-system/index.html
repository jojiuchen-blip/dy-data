规范如何生效

正式 token、可视化规范与测试共同约束运行时设计契约。

token -> preview -> decision -> check
1. 正式 token 从现有 CSS、业务页面和问题清单提取，不凭空发明。
2. HTML 预览 把颜色、排版、组件、表格、移动卡片都画出来。
3. 正式规范 在 tokens.json 与完整 HTML 中维护已生效的设计决策。
4. 运行时绑定 通过 design-tokens.css 与业务实现保持核心 token 同步。
5. 测试拦截 关键值和现有 CSS 绑定，避免协作时悄悄漂移。

图标体系

图标只作为动作、导航和状态的辅助信号，来源、尺寸和可访问名称必须统一。

@iconify/react · @iconify-icons/solar

库与入口

  • 项目唯一 UI 图标库为 @iconify/react + @iconify-icons/solar。
  • 业务代码统一通过 apps/web/src/components/SolarIcon.tsx 引用，不在页面里临时手写 SVG。
  • 默认变体为 Solar linear；查看、复制、退出、设置、详情等操作图标都走 linear。
  • bold-duotone 只用于移动底部导航激活态、一级导航强调、品牌或模块入口。
  • 同一语义有普通态和强调态时，在 SolarIcon.tsx 中拆成 cluesLine / clues 这类明确名称。
  • icon-only 控件必须提供可访问名称；装饰图标用 aria-hidden。
  • 规范页示例也必须引用与 SolarIcon.tsx 同名的 Solar symbol，不允许文本字形、CSS 箭头或重复手写 path。

明细工作台规则

  • 全局工作区：登录后的业务页面默认铺满 Shell 可用宽度，不再使用居中窄容器；具体阅读宽度由页面内卡片、表格或弹层自己控制。
  • 桌面端：明细工作台用于线索明细、订单明细这类高密度长表；在全宽基础上增加高度 calc(100vh - topbar) 和内部滚动。
  • 滚动归属：桌面外层页面不纵向滚动，只有结果表格区域上下滚动；移动端恢复自然页面滚动，卡片和分页按内容顺序排列。
  • 筛选区：桌面优先单行密度；移动端使用折叠筛选、已选条件摘要和明确的“收起”操作。
  • 分页：移动端只保留上一页、可编辑页码和下一页，不展示每页数量、首页、末页或独立跳转按钮。
  • 适用边界：看板、后台表单、解释型页面使用全宽普通页面容器，但不套固定高度明细工作台。

协作约束

其他人参与开发时，也需要有明确边界，避免又回到散落硬编码。

guardrails
  • 新增颜色：同步更新 tokens.json、本页和相关测试；候选工件只作为不可变历史记录。
  • 主题实现：只通过共享 ThemeProvider 和 ThemePicker 读写 dydata.theme.preference；页面不得直接读取系统主题或 localStorage。
  • 双主题验收：新增组件必须同时检查 light 和 dark，状态色继续表达成功、警告、错误和信息，不得统一替换成品牌橙。
  • 项目署名：Powered by SPACE AI Native 仅用于 dy-data；SPACE 只使用确认的 SVG，POWERED BY 与 AI NATIVE 使用 Ethnocentric Regular。
  • 新增组件：先判断它属于按钮、字段、状态、卡片、表格还是页面骨架，不要单独发明一套半径和阴影。
  • 新增 KPI：复用统一白底圆角指标卡，不增加 tone、彩色顶线或彩色卡面；优先级通过顺序、标签、数值和说明表达。
  • 用户文案：内部生产值不得直接展示；通过共享映射转换，未知状态 / 未知类型 / 未知原因不得回显原值。
  • 导航层级：二级导航不使用图标；父子路径同时命中时，只允许最长路径对应的导航项进入当前页状态；稳定子页面使用 TertiaryNav、真实链接和 aria-current="page"。
  • 品牌入口：浏览器标签图标使用版本化橙色资产，浅色与深色浏览器 chrome 分别验证对比度。
  • 新增长列表：桌面优先表格；移动端卡片或摘要进入 DYDATA-5 范围，不把宽表直接塞进手机。
  • 新增明细长表：如果用户主要任务是筛选后逐行处理记录，桌面端使用明细工作台模板，保证分页可见且只让结果表格滚动。
  • 新增 sticky/fixed：必须声明对应 z-index 层级和导航避让间距，避免层叠互相遮挡。
  • 规范变更：先更新完整正式 HTML，再同步 tokens.json、产品 CSS 和测试。
  • 移动端边界：本页所有移动端信息架构与移动端明细样例均为 DYDATA-5 未来范围，不声明为当前运行时行为。
