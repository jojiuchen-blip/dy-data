2. `apps/api/dy_api/pdca_readonly_access.py`
3. `apps/api/dy_api/pdca_source_schema.py`
4. `apps/api/dy_api/pdca_source_evidence.py`
5. `apps/api/dy_api/routes/pdca_sources.py`

镜像应基于核实的当前API不可变镜像ID，仅覆盖上述文件；不重新安装依赖。构建环境不挂载生产数据库或配置。上线前先核实候选镜像与旧镜像的其他应用文件相同。

如使用Compose替换API，限定服务为`api`并使用`--no-deps --no-build`；不得启动`migrate`依赖。使用独立镜像覆盖配置，不编辑现有生产环境文件或基础Compose文件。旧服务配置必须复用且验证，避免因命令工作目录或环境缺失产生配置漂移。

API健康并不代表网关已指向新地址。检查网关访问；仅在已获明确许可且配置检查成功后，必要时执行平滑重载。不得重启网关容器作为替代。
