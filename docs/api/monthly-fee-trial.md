# 月度费用内部试算

DYDATA-104 于 2026-11-20 确认总部和财务可先核对已有试算。正式账单尚未生成、部分门店待核或账单尚未确认时，授权管理员可读取和下载试算。门店身份无此权限。每个请求重新核对费用方向页面权限及当前门店范围。

## 读取与下载

授权管理员可在财务的推广服务费、管理服务费页面和全国门店月度榜单中查看内部试算。正式账单尚未发布时自动展开试算，其他账期可手动打开。试算沿用所选账期，全国榜单从门店汇总开始，可切换至逐券明细。

首次计算的自然月由调度器冻结该月的有效门店关系。升级前已有试算的未完成账期，继续提供上一轮结果。运维使用 `scripts/ops/freeze_monthly_store_evidence.py` 对照原账期名单和补证清单预演，按同一摘要追加证据。调度器据此生成新版本任务。已经正式出账的门店保留原账金额及明细。

业务负责人明确确认指定账期的账号与门店关系时，运维可用 `--confirmed-account-link` 预演并追加一条确认记录。清单记录实际确认时间、依据引用、账号、抖音号和系统门店。服务核对冻结名单的认证资格、门店存在时间以及已冻结的账户和 POI 关系，遇到冲突时返回待核原因。确认记录只适用于指定账期，沿用同一预演摘要后写入。

`GET /api/v1/admin/finance/trial` 与 `GET /api/v1/admin/finance/trial/export` 共用筛选。

`GET /api/v1/admin/finance/trial/stores` 提供门店汇总，`GET /api/v1/admin/finance/trial/stores/export` 下载独立中文门店汇总 CSV。四个入口使用相同筛选、当前权限和指定试算版本。门店汇总的 `total` 为门店桶数，包含全范围管理员可见的“归属待核验”桶。门店行提供已算金额和已算、待核、排除、候选券数，未知归属桶的金额为 null。已有真实已算零金额的门店保留 0。

| 参数 | 含义 |
|---|---|
| month | YYYY-MM 账期，必填 |
| feeDirection | PROMOTION 或 MANAGEMENT，必填 |
| storeId | 可选的授权门店 |
| productType | 商品类型，默认 all |
| q | 搜索门店名称、门店 ID、SAP、订单 ID 或券 ID |
| recordStatus | CALCULATED、PENDING 或 EXCLUDED，可选 |
| publication_id | settlement 分析版本，下载必填，读取可省略以取得当前完整版本 |
| page / pageSize | 读取分页，pageSize 默认 50，最多 100；下载使用全部命中行 |

响应沿用 `{data, meta}`，字段为 camelCase。`meta.publication.id` 固定汇总、分页、后续筛选与下载的试算版本。试算使用 settlement 发布版本，正式开票记录使用 finance 发布版本，各自的页面金额和文件均绑定各自读取的完整版本。

`data.summary` 提供已算费用小计、已算券数、待核券数、已排除券数、候选券数及覆盖是否完整。候选券数按券去重，同一张券可同时有已算原费和待核事件，因此各状态券数不能简单相加。没有可用费用且仍待核时，小计返回 null。`data.list` 中待核与排除行的计费基数、费用均为 null。真实已算零费用保留 0，退款调整保留负值。

`data.coverage` 提供完整采集天数、影响范围是否待核、待核原因与券数，以及当前筛选和权限范围说明。无销售门店依据的记录仅全局范围管理员可见，限定门店管理员的计数、金额和文件均排除这些记录。范围未知时继续显示待核说明。

后台构建会批量使用原始销售名称、月末名单和一份冻结映射，确定待核记录的唯一门店可见范围。缺门店依据、重名或两路映射冲突的记录继续保留全局待核。所用映射版本随试算覆盖元数据冻结，新补证插入通过来源计数触发后续试算发布。

CSV 固定为 UTF-8 BOM，中文文件名、列名和状态，金额使用元和两位小数，长 ID 及公式文本按现有下载规则转义。逐券文件附试算版本、覆盖说明和每条费用，待核金额留空并附“金额待核”。逐券文件的费用列可直接加总。

门店汇总 CSV 的“汇总层级”为“门店”或“总计”，末尾有独立总计行，空筛选也可导出该行。总计金额和券数基于当前筛选全范围独立聚合及去重，同券跨店的原费或调整不会重复计入总券数。将该行与各门店行区分后核对金额。未知归属桶的层级为“门店”、名称为“归属待核验”，总计行的名称为“全部筛选范围”，两者均保留空门店 ID。

下载最多 100000 条券记录或门店桶，超限返回 413。逐券空结果保留中文表头。汇总下载保留总计行，`X-Export-Result` 为 SUCCESS，`X-Export-Data-Rows` 单列实际门店行数。

## 来源与状态

后台发布事务将已有权威原费、调整及本次月结任务的逐券诊断写入 `dashboard_publication_fee_trial`，与月份覆盖元数据一同冻结。GET、筛选和下载仅查询冻结数据。新发布失败继续使用已有完整版本，指定版本过期返回 410，无该账期试算标记返回 `PUBLICATION_TRIAL_NOT_READY`，不会改读其他月份或版本。

内部试算保留此前按冻结月末名称、账号资格和门店依据算出的金额。正式月结对新增的映射补证继续执行最新校验。已有试算的查看与下载独立于补证进度，源账单确认、发票、付款均沿各自正式写入资格核验。

结构迁移为 `20261120_0073`，依赖 `20261120_0072`。发布 `settlement` 契约更新为 `commission-product-type-v4-trial`。部署前须用新应用完成对应分析版本构建和既有兼容切换门禁。已发布试算存在时，0073 拒绝降级删除，应用回退通过前滚恢复保留证据。
