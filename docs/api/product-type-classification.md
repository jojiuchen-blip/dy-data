# 商品类型与默认账期（DYDATA-104）

本合同承接 DYDATA-104 在 2026-10-26 的范围更正。普通后台、核销、线索及订单分佣使用真实 `product_type`；独立打榜继续使用原有范围语义。

## 普通配置与查询

- 普通 SKU 列表、单条/批量编辑、分类导入和可见性配置不再要求 `product_scope`。类型有效即为分类完整；空白、`all`、`unknown`、`keep` 不能作为新分类保存。旧 `PARTIAL` 状态枚举保留兼容，当前分类统计为 0。
- 分类导入新模板为 `skuId,productType`。旧三列模板继续接受，但 scope 列忽略；历史待提交批次也不能重新写 scope。导入预检返回 `normalizedTypeCount` 和 `normalizationNotice`，提示按精诚养车规则归一的行；提交后重新读取实际类型。
- 单条编辑保留乐观版本校验，批量/导入保持整批事务、权限、冲突和幂等校验。全局分类写入仍只允许全国管理员。
- 普通接口接受但忽略旧 `productScope` / `product_scope`，不会将其值当作类型。类型按实际名称精确匹配，不经过范围/类型配对校验。线索的 `jingcheng`、`byd` 不再作为普通查询的范围别名。
- 普通筛选元数据的旧 scope 集合为 `all` 或空兼容字段，配对映射为空；类型选项受账号门店权限限制。沿用 DYDATA-72，分类本身不作为隐藏业务数据的白名单。没有授权门店时仅有 `all`。分析页面从对应发布版本读取类型，不借用全局商品目录绕过权限。
- 单店分账切换门店时，类型合法性按当前用户全部授权门店的同版选项校验。目标门店没有该类型数据时返回空结果，仍拒绝未知类型与越权门店。
- legacy `/sku-rules` 纯分类修改返回 `job_id=null, rebuild_status=not_required`，不排队费用重建。既有费率/服务标记修改仍遵循原重建合同。

## 分类时间与财务保护

当前商品目录仅对内部 `product_scope == 精诚养车` 的精确目标强制类型为 `精诚养车`，包括已有其他类型、已下架的目标 SKU。同步、单条、批量、导入及旧分类接口保持一致；其他范围保留人工类型。不按名称猜分类，不从新类型反推 scope。

核销和线索分析在后台构建时冻结当时目录类型；当前线索工作队列使用同一精确解析规则即时查询。核销按已存 SKU 查目录；线索优先使用唯一订单 SKU、再使用精确 SKU，产品级候选只有全部类型一致且有效才可采用。歧义或缺档案保留来源类型，不复制或倍增订单。

历史费用、账单、确认与发票的 `product_type`、`product_scope`、行键和金额继续使用生成时快照。普通查询忽略范围筛选，但不能把多份兼容汇总重复累加：优先使用原 `all` 分区；类型筛选仍按该版本冻结类型。历史版本的真实类型会出现在有权限的筛选项中，因此目录转换不会使旧账单类型消失，也不会把旧费用静默改名。

当前目录转换仅影响目录类型和人工修改审计字段，不改费率/实收、不生成账单、不重算历史费用。具体预演与应用见[运维步骤](../ops/product-type-conversion.md)。

## 发布兼容

`sales`、`clue-overview`、`settlement` 来源指纹包含 `product-type-v2` 合同版本，防止代码升级后复用旧语义构建。核销和线索旧版无合同标记时，默认请求返回 `PUBLICATION_NOT_READY`，指定旧版本返回 `PUBLICATION_EXPIRED`；等待独立 worker 发布新版本，GET 不构建。

旧 settlement/finance 的冻结财务事实可按兼容读取合同继续使用。`finance` 与独立 `douyin-ranking` 的来源指纹不因本次合同升级而改变。分析同页、筛选、导出继续固定同一 publication，当前权限始终重新校验。

## 默认月份及状态

全国门店月榜、单店分账、订单明细在没有明确账期或账单上下文时，默认 **Asia/Shanghai 上一完整自然月**。10 月为 9 月，1 月为上一年 12 月。明确月份、固定账单上下文和下钻返回优先；分页、导出、刷新保留实际查询月份。无月份菜单入口不读取旧的本月默认缓存，不自动退到更早月份或累计。

未发布、账期未完成、读取失败、无权限与正常零业务分别处理；错误查询不显示旧月份数据或假装“共 0 条”。后台正在更新或更新失败但仍有完整版本时，继续按发布元信息显示旧版状态。页面行为仍然只读，不能触发采集、结算或账单生成。

## 独立打榜例外

`DouyinRankingPage.tsx`、`DouyinRankingExportDialog.tsx` 的全部/精诚养车/比亚迪本品选项、scope 查询、排序、下钻和导出保持原合同。保留目录内部 scope 及可见性配置的历史 scope 值；普通后台不再提供修改入口。测试必须独立覆盖此例外，不能仅看页面标签判断语义。
