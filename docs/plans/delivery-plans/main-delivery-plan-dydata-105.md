## 2. 分工与边界

主线程负责统一权限架构、任务分派、冲突合并、最终提交审查与验收；worker 只实现指定切片，不能扩大范围或替主线程宣布完成。所有写 worker 使用隔离工作树；同一文件需由单一写集持有或串行集成。

| 切片 | 所有责任与可验证交付 | 边界 |
|---|---|---|
| A | 角色/会话迁移、账号管理、全局写服务端约束及管理员界面 | 全国管理员可新增/变更所有角色；受限管理员仅管理授权范围内门店账号，不管理管理员、不扩大范围；无账号删除 |
| B | 有界导出元数据、真实代理回归、财务分页及调查证实的按钮缺陷 | 不改金额算法、锁账、来源就绪、确认/发票/幂等语义；禁止只增大代理缓冲掩盖响应头问题 |
| C | 账户/POI 精确解析、授权解析接口与合并多选、列表/总数/导出同条件 | 同批 OR，与其余条件 AND；全部未匹配不得退回全量；不改线索归属与核销状态 |
| T1.1 | 最终集成版本的按钮逐项证据与发布准备 | 未测、失败、缺资产明确记录；不执行生产试写或擅自部署 |
